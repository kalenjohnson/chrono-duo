## New

- True widescreen: the mobile port crops 64 rows off the SNES frame. Fields now render the full 224 rows plus the extra 16:9 width, and the overworld gets a wider view too. Toggle under Settings > Graphics (takes effect on the next launch).
- Settings is now a full-screen sheet with a tab rail (Imports, Graphics, Maps, Speed, Mods) instead of page flipping. Option pickers are wide `◂ choice ▸` controls, and the whole sheet is navigable with the d-pad: left/right switches between rail and content, up/down moves a focus ring, A activates. Gameplay input is never taken while Settings is closed.
- Multi-part mods (like Pixel Demaster's ~30 sub-mods) are grouped under one parent row with option groups such as Font or Button Prompts. Picking one choice in a group disables its siblings; turning the parent off disables everything under it.
- The mod catalog is versioned, so a newer catalog bundled in the APK is no longer shadowed by a stale cached copy. Reinstalling a catalog mod replaces the existing copy instead of duplicating it.
- Battle: Tech and Item rows commit on a single press. The targeting band follows the game's own target-selection state, so it no longer vanishes on a slow player or lingers after cancelling. The confirm button is labelled with the chosen action, the game's resolved target is highlighted on the enemy or party row, tapping a row moves the cursor, and tapping the highlighted row confirms.
- Battle results now report item drops, gold, level-ups, and newly learned techs, dual techs, and triple techs with the character and tech names filled in.
- Second screen top strip: the fast-forward badge stays in the top-right corner in and out of battle, the gear and AUTO chips crossfade in place across the battle boundary, and the eye toggle only appears in fights with a hidden-info enemy. The eye is drawn as an actual eye, slashed when real numbers are forced on.

## Fixed

- Swapping a party member from the menu on the world map now updates the second screen immediately instead of waiting for the next location to load.
- Battle Tech/Item submenus needed a second press on any row that wasn't already focused, which read as a hang on the second screen.
- The fast-forward badge used to jump onto the menu button when a battle started, overlapping the submenu back chip.
- Mods picker stepped to the wrong option when moving forward from "None".
- The full-screen Settings background could disappear after the second screen was recreated (e.g. after sleep).
- The mod folder scan removes folders that contain only dotfiles.

## Notes

- Install over your previous build; don't uninstall first or you'll lose local ChronoDuo settings and saves not backed up elsewhere.
- Still requires the official CHRONO TRIGGER (Upgrade Ver.) installed from Google Play. ChronoDuo redistributes none of Square Enix's code or assets.
- True widescreen is off by default; turning it on or off takes effect on the next launch.
- Known limitation: if two installed mods change the same file, the one that comes first alphabetically by folder name wins; there's no in-app conflict resolution yet.
- Known limitation: RAR5, gzip, and tar-packaged mods aren't supported yet — only zip, 7z, and RAR4.
