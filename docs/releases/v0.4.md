The headline feature is mod support: a full in-app mod manager with a curated catalog, in-app Nexus downloads, and a loader that handles most common mod formats. Also new: fast-forward, an Auto Battle toggle on the bottom screen, save-import fixes, and second-screen polish.

## New

- Fast-forward: hold R2 to speed the game up, with the speed set under Settings > Speed.
- Auto Battle toggle on the bottom-screen battle panel, mirroring the game's own auto-battle mode.
- Mod loader: drop mods into a folder on your device and ChronoDuo applies them automatically, with no changes to the base game files. Supports plain files, `.ctp` mod packages, `.zip`, `.7z`, and `RAR4` archives (RAR5, gzip, and tar are not supported and will show a clear error).
- Mods page in Settings lists a curated catalog of mods (SNES-style overworld sprites, Pixel Demaster, a wooden SNES-style menu, Orchestral Wonders, an FMV remaster, and more). Tap "Get" to open the mod's Nexus page right on the bottom screen and download/import it in-app; a file picker and direct `.ctp` file opening also work.
- Mods that replace whole game archives (like a full music repack) are supported: only the actual changed files are applied, so they install as a lightweight overlay instead of a full archive swap.
- FMV cutscene replacement: mods can swap in new cutscene videos (plain `.mp4` or in the original format).
- Custom font mods: a mod can supply its own in-game font, and it's now used consistently across every screen, including the second screen.
- The Mods list scrolls, uses larger text and buttons, wraps descriptions onto two lines, shows extraction progress, and reports imports plainly even when one download unpacks into several mods.
- SNES/DS save import shows its result as an on-screen message, so success or failure is visible at a glance.
- Wider mod-replacement FMVs (e.g. 16:9 remasters) now scale to fit the screen instead of being cropped.

## Fixed

- Save import wrote a format version the game rejected, so freshly imported saves could appear empty.
- Companion-screen art (portraits, menu chrome, map markers) now correctly picks up mod replacements instead of always using the original files.
- The companion screen no longer loses its Mods list/state after the device sleeps and wakes.

## Notes

- Install over your previous build; don't uninstall first or you'll lose local ChronoDuo settings and saves not backed up elsewhere.
- Still requires the official CHRONO TRIGGER (Upgrade Ver.) installed from Google Play. ChronoDuo and its mod loader redistribute none of Square Enix's code or assets — mods are files you add yourself.
- Known limitation: if two installed mods change the same file, the one that comes first alphabetically by folder name wins; there's no in-app conflict resolution yet.
- Known limitation: mods that replace textures already loaded into memory (e.g. switching art mid-session) may need a full game restart to actually show up.
- Known limitation: RAR5, gzip, and tar-packaged mods aren't supported yet — only zip, 7z, and RAR4.
