## New

- Mod priority order: the Mods tab lists installed mods in a user-set order with ▲/▼ buttons on each row. When two mods change the same file, the one higher in the list wins. Grouped downloads (a main mod plus its option choices) move as one block. The order is saved in `mods/.order`; mods not yet listed fall back to alphabetical after the ordered ones. The d-pad focus ring follows the mod you moved.
- Save import accepts Steam/PC saves: drop in a `save_NN.bin` from the Steam version alongside SNES `.srm` files. A Steam file holds one save, so the slot picker is skipped; destination choice and overwrite confirmation are unchanged.

## Fixed

- The second screen now shows renamed characters' names. It was reading a stale name table that only the gallery and ending scenes refresh, so a renamed character kept its default name. Portraits are now chosen by character id instead of by name, so renamed characters no longer fall back to the colored-initial placeholder.

## Notes

- Install over your previous build; don't uninstall first or you'll lose local ChronoDuo settings and saves not backed up elsewhere.
- Still requires the official CHRONO TRIGGER (Upgrade Ver.) installed from Google Play. ChronoDuo redistributes none of Square Enix's code or assets.
- Known limitation: RAR5, gzip, and tar-packaged mods aren't supported yet — only zip, 7z, and RAR4.
